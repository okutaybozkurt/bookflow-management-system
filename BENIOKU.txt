# BOOKFLOW - KİTAP SATIŞ VE STOK YÖNETİM PLATFORMU

Frontend: React (Next.js)  |  Backend: PHP / Laravel REST API  |  Veritabanı: MySQL

Kurulum, API uç noktaları ve demo hesaplar için README.md dosyasına bakın.
Veritabanı mimarisi ve ER diyagramı için docs/ER-DIYAGRAMI.md dosyasına bakın.

Kısa kurulum (iki ayrı terminal):

1) Backend
   cd backend
   composer install
   cp .env.example .env        (DB_USERNAME ve DB_PASSWORD değerlerini düzenleyin)
   php artisan key:generate
   php artisan migrate --seed
   php artisan storage:link
   php artisan serve           (http://localhost:8000)

2) Frontend
   cd frontend
   npm install
   cp .env.local.example .env.local
   npm run dev                 (http://localhost:3000)
